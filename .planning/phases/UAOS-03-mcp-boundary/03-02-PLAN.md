# 03-02 — One Controlled Stdio Capability

Install the two exact selected SDK packages, activate their admission record, and implement the fixed read_doc boundary behind the established registry. Earlier iterations and public result contracts remain supported.

## Tasks

1. Implement a host MCP read adapter with consent before session creation, pinned discovery, bounded capability metadata, exact schema comparison, strict arguments/results, matching correlation receipts, safe failures, and finally-based session close. Use injected sessions for adversarial tests.
2. Implement the SDK stdio session, a controlled read-only document server, explicit iteration 3 selection, and a host consent setting. Pass signals/timeouts through modern discovery/list/call and suppress child output outside the protocol.
3. Prove a real SDK client/server exchange, malformed metadata/results, denial, cancellation, correlation, and child lifecycle. Verify CLI/HTTP parity and earlier iterations.
4. Write the Iteration 3 guide, package evidence, requirement traceability, and summary. Run full validation before advancing and preserve pending Phase 3 approval and stability.

## Acceptance

- Denial or invalid arguments/context construct no session and spawn no process.
- A wrong protocol, server identity, tool schema, or duplicate selected tool prevents remote invocation. Forged annotations never grant permission or alter host policy.
- Unrelated advertised tools remain inaccessible. Oversized, malformed, error, incomplete, contradictory, or mismatched-correlation results fail before later model work.
- Close runs on success, discovery/list/call failures, and cancellation. Later settlements cannot change the returned outcome.
- Real calls carry the host runId/callId as namespaced metadata and return a matching receipt. Logs contain safe metadata only.
- MCP SDK imports stay in adapters. No provider, remote service account, HTTP MCP transport, RAG, database, memory, UI, or approval workflow is added.
- Strict project/core compilation, all tests, build, package pins, links, and evidence pass on Node.js 24.
