# 03-01 — Pinned MCP Contracts

Define [ADR-0005](../../../docs/architecture/decisions/ADR-0005-mcp-boundary.md), consent, discovery, call correlation, dependency admission, and a provider-neutral session port before adapter implementation. Pin revision 2026-07-28 and SDK client/server 2.4.0 using verified official metadata.

## Tasks

1. Define strict consent, discovery, correlation, remote-call, and boundary error contracts with no SDK imports in core. Extend optional tool invocation context without changing stand-alone two-argument handlers.
2. Preserve the original six direct dependency pins. Validate the separate Phase 3 selected-package admission record and allow its additions only when its installation state is active. Add contract tests before dependent implementation.

## Acceptance

- Invalid, mismatched, or auto-granted consent is rejected by the host contract.
- Only the selected modern revision and expected server identity can pass discovery validation.
- Correlation IDs are opaque and filename-safe, without questions or raw content in the context.
- Pending dependency admission leaves the manifest and lock unchanged.
- Existing iteration tests, strict typecheck, and core-only compilation pass.
