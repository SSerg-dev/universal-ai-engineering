# 04-02 — Controlled Grounded Answering

## Tasks

1. Implement deterministic chunk/identity/embedding fixtures, ingestion, and retrieval use cases with replaceable ports. Prove Unicode coverage, profile isolation, result validation, and cancellation.
2. Activate selected pg dependencies and implement bounded parameterized PostgreSQL/pgvector storage with immutable manifest, transactional document replacement, active search, retained citation resolution, and safe failures. Add explicit disposable-database tests.
3. Add request-scoped grounded model validation, canonical extractive rendering, an iteration 4 runtime, CLI/HTTP parity, and a read-only citation resolver. Reject unsupported or unobserved claims before terminal success.
4. Close teaching/evidence, requirement/threat links, full offline validation, and real database tests. Publish atomic coherent commits and preserve pending human approval.

## Acceptance

- Identical ingestion is idempotent; an interrupted/failed replacement exposes no partial revision. Concurrent replacement serializes, while earlier revisions remain resolvable.
- Search admits only selected-index active revisions with a matching vector profile. Ranking/thresholds are explicit and deterministic for ties.
- SQL-shaped values never become SQL identifiers or statements. DB errors/credentials/text do not enter public failures or journals.
- Quotes resolve exactly to observed indexed passages. Forged identities, altered quotes, missing citations, duplicates, and unsupported prose are rejected before run.succeeded.
- Empty evidence yields a typed no_evidence abstention after exactly one tool call. Retrieval failure yields failure, not abstention.
- Real PostgreSQL tests prove persistence, rollback, update/retention, concurrency, and query isolation. The explicit DB command fails when infrastructure is unavailable rather than silently skipping.
- Iterations 1–3, strict core compilation, package admissions, links, traceability, build, and full tests pass.
