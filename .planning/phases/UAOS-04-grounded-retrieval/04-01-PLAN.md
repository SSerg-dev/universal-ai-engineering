# 04-01 — Grounded Retrieval Contracts

Define immutable document/passage identity, bounded profile-tagged vectors, a replaceable repository, and versioned grounded results before implementing ingestion or PostgreSQL.

## Tasks

1. Record ADR-0006: canonical text, UTF-16 spans, stable hashes, immutable manifest, active and retained revisions, exact cosine search, and extractive grounding.
2. Define strict schemas and core ports for embeddings, content identity, atomic document replacement, search, and exact citation resolution. Preserve the legacy result schema.
3. Verify malformed vectors, spans, duplicate/cross-index observations, unsupported result shapes, and dependency/core boundaries. Record RED evidence honestly and select packages separately from earlier admissions.

## Acceptance

- Every citation names index, document, immutable revision, passage, and half-open span.
- Invalid vectors, dimensions, identities, spans, cross-index/duplicate observations, and missing grounding fail strict schemas.
- Answered results require claims/citations; abstention has none. Behavioral quote/provenance checks are explicitly assigned to 04-02.
- Core ports contain no Node crypto, PostgreSQL, provider, or transport types.
- Contract checks and full existing validation pass before adapter implementation.
