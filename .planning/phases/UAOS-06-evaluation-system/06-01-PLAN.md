# 06-01 — Evaluation Contracts

1. Record ADR-0008 with immutable dataset revision, separate scorer version, six quality dimensions, explicit denominators/coverage, safe reports, awaited persistence, and known-regression evidence.
2. Define strict cases/expectations, checks, thresholds, case results/reports, and infrastructure-free executor/report ports.
3. Prove duplicate/contradictory cases, missing outcome families, impossible metrics, raw report content, and inconsistent gates fail. Run full compatibility validation before dependent implementation.

Acceptance: a report identifies its dataset/scorer and each run; absent coverage cannot become a passing 100 percent; no question/quote/raw exception field is admitted; all prior iterations remain compatible and approval remains separate.
