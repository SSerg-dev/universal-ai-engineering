# 07-01 — Safe Telemetry Contracts

1. Record ADR-0009 with optional telemetry versus required journal policy, per-trace buffering, bounded post-result flush, correlation, redaction, measured timing, metrics, and honest incomplete diagnosis.
2. Define strict log/span/run/state/quality record schemas and narrow sink/read/clock/ID ports without provider, framework, transport, or filesystem types.
3. Prove content/secret fields, invalid identities/status/durations/rates, oversized records, and false complete diagnosis are rejected. Run full earlier-iteration validation before dependent instrumentation.

Acceptance: raw content has no telemetry field; counts/rates and error labels are bounded; missing telemetry is distinguishable from a successful complete trace; optional exporter failure cannot redefine primary outcome or required journal policy.
